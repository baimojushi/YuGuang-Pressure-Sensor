# 余光在线版 · MVP 0

保留原项目手机适配界面。部署使用 Sites / Cloudflare Worker，D1 持久化配对、消息队列、设备指令与回执，私有 R2 保存原声。尚未连接 Supabase，也尚未接真实硬件。

Sites 登录身份隔离每位使用者的数据；两个公开测试账号仅是同一位访问者内部的亲友/接收角色，不代替真实账户体系。网站默认仅所有者可访问。双方模拟体验在同一登录身份的两个标签页进行；真实亲友跨账号连接需后续实施。

数据库采用每户一条受版本控制的记录，所有共享状态修改均比较版本并重试，避免多个页面同时写入时覆盖消息。上线版上限 1000 条历史、50 条待传达、100 个音频附件；适用于黑客松有限用户联调，未做大规模负载验证。

- `app/cloud-api.mjs`：云端 API 和原子状态转换。
- `db/schema.ts` 和 `drizzle/`：数据库 schema 与托管迁移。
- `public/`：复用本机版 UI 和 PWA 页面壳。
- `tests/cloud.test.mjs`：云端 API 的状态、并发、权限、原声和解绑测试。
- `worker/index.ts` 和 `scripts/vite/`：保留 Sites 运行集成。

运行前安装依赖，然后执行 `npm run dev`。本地 preview 登录入口为 `/signin-with-chatgpt?return_to=/`。云端的 D1/R2 由托管平台创建。代码中不包含真实访问密码或服务端密钥。

真实硬件除自己的设备密钥外，还需获得本站的托管服务访问授权；私有网站的外层鉴权不能仅靠应用内设备密钥跳过。接口格式保留 `/api/hardware/lamp-001/...`，但本次未声称硬件已联调完成。
