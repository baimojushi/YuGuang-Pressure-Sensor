# 余光控制面板 · 原版视觉统一说明

日期：2026-10-30

## 视觉依据

以原始交接版的 `docs/preview-desktop.jpg`、`public/style.css`、`public/visuals.js` 为准：
- 纸张底色 `#f5f3ed`、卡片 `#fffefa`、主文字 `#34483e`、强调绿 `#486351`。
- 原生圆角卡片约 17px；描边轻而浅，靠间距和层次分区，不依赖高饱和色块、数据大盘组件。
- 保留余光玩偶的原始 SVG 轮廓、奶油色渐变、暖光、底座与表情。
- 控件沿用首页的线条图标、选中描边、暖色按钮与中文叙述。

## 本次调整

1. `public/device-panel.css`：共用原有全局设计变量，删除整页强渐变和单独后台配色；控制卡与状态区恢复纸张质感。
2. `public/device-panel.js`：保留属性开关、呼吸、休息、预览、设备密钥和模拟灯操作；板块标题调整为余光自己的叙事文案。
3. 自由休息沿用原有功能，但在「我的余光」页将冷蓝色卡片、浏览器原生直角时长按钮改为原版暖白卡片与胶囊选项。
4. 灯语选项保持两列（窄屏也如此），轮廓图标、细线框、选中态复用原版「一份心意」的视觉逻辑。
5. `lingji-h5/src/views/Yuguang/HomeView.vue`：平台控制页同步设计变量、暖白纸卡和原版玩偶 SVG 底座与表情，保留SDK数据回报机制。
6. `hosting/public` 已同步 `public` 的控制面板文件。其他页面视觉不变。

## 测试与边界

- 页面样式静态预览以演示设备数据渲染，不代表真实设备在线或硬件执行。
- 设备状态和开关由现有接口决定；灵机平台字段仍需按真实产品的物模型填写。
- 视觉改动不影响持续呼吸采集接口与权限隔离。
- 真实设备执行效果需线下联调。
