# 在线部署

同一部署提供正式版 / 与展示版 /demo。线上使用 Sites 平台个人登录，首次设置自己的称呼，不再选择发送者或接收者身份；不同个人身份可通过邀请码配对。展示版无需使用正式资料，使用单独示例身份与模拟灯。

2026-10-30 起，正式空间 live-v2 使用专用 Supabase 项目 yuguang-live 的 PostgreSQL 与私有 Storage，未导入种子数据。展示空间 demo-v2 继续使用 D1 与 R2。此前版本的 households 表不删除、不导入正式空间。网站访问权限为 public，个人记录 API 仍要求本人身份；设备使用独立密钥。Supabase Auth 尚未接入，线上沿用 Sites 个人身份登录。

源码规范：根目录 public/、shared/ 为唯一业务实现，hosting/ 为生成副本。先运行 npm test、npm run check:sync；同步到已有 Sites checkout 后，按 Sites 源码同步、构建、保存版本、部署流程发布。仅 push GitHub 不会自动让 Sites 上线。

展示网址：https://yuguang-emotional-presence.red-rice-3957.chatgpt.site/demo
