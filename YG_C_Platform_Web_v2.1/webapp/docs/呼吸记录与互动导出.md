# 呼吸记录与互动导出

2026-10-30 更新：桌搭按开机持续采集设计，新增「此刻的呼吸」与自动分段保存，详见 [持续呼吸采集](持续呼吸采集.md)。下文保留原历史分段上传与练习说明。实时频率来自硬件计算，不假装已有逐次呼吸波形或情绪模型。

本次在原有灯语 MVP 上增加本人呼吸记录和日、周、月互动统计。设备呼吸记录只属于设备主人；双方都可保存各自的引导练习，不随配对共享。解绑保留本人记录。正式版使用独立身份和设备绑定，初始没有示例账号或记录；展示版位于 `/demo`，与正式版隔离。当前协议以《硬件API.md》为准。

## 硬件上传

`POST /api/hardware/:deviceId/breathing`

请求头：`X-Device-Key: <当前设备的密钥>`、`Content-Type: application/json`。主人通过 `POST /api/device` 绑定设备，取得唯一 ID 与只显示一次的密钥。真实硬件使用正式版 API；展示版模拟器使用隔离的 `/api/demo/` 路径。

```json
{
  "eventId": "设备生成的唯一记录ID，断网重试保持不变",
  "startedAt": 1793232000000,
  "endedAt": 1793232060000,
  "samples": [
    { "offsetMs": 0, "rpm": 12.5 },
    { "offsetMs": 30000, "rpm": 13.0 }
  ]
}
```

以上是协议示例，不会自动写入真实记录。时间戳为 UTC 毫秒；显示和统计使用北京时间。结束时间必须晚于开始时间，单次最长 24 小时，最多允许 5 分钟设备时钟误差。单条包含 1–720 个点。`offsetMs` 必须严格递增且位于记录时长内；`rpm` 为设备算法输出的每分钟呼吸次数，大于 0 且不超过 120（传输校验范围，不是健康判断范围）。设备可按 10–60 秒一个采样值上报，原始压力波形不直接塞入此接口。

首次写入返回 `{ "id": "..." }`；同设备同 eventId 的相同内容返回 `{ "id": "...", "duplicate": true }`。重用 eventId 上传不同内容返回 409；无效采样返回 400；错误密钥返回 401。设备断网期间需自行缓存；联网后重传相同 eventId。

设备需自己完成真实传感器采集、信号处理、时钟校准和记录分段。APP 仅保存和显示硬件上传的结果；不会凭灯语动画推算呼吸。平均数是上传采样值的算术平均，不做情绪或健康诊断。没有采样时，页面显示无记录。

## 本人查看与统计

### 自己的呼吸练习

首页与记录页均提供 1、3、5 分钟跟随引导练习。动画提示吸气/呼气，每段 4 秒，不屏息。练习的时长与完成情况由前台计时器记录；没有测量真实呼吸次数，也不声称实际跟随的效果。暂停、切后台、离开练习页面和进程长时间休眠不补算时长；刷新后从本标签页草稿恢复为暂停。达到目标自动保存；提前结束按实际计时秒数保存为 `ended_early`。未保存成功的计时保留在本标签页，可重试，不会显示为已入库。

`POST /api/breathing/practice` 使用当前用户的 Bearer 认证，双方账号都可保存自己的练习，不依赖配对或硬件在线。请求体包含 `eventId`、`startedAt`、`endedAt`、`durationSec`、`targetSec`。`targetSec` 只能为 60、180、300；`durationSec` 为至少 1 秒的实际计时整数，不超过目标和实际经过时间。同用户同 eventId 相同内容幂等；改写已有内容返回 409。

返回记录 `source: "guided"`，包含实际时长、目标和 `completed|ended_early`，`samples: []`、`sampleCount: 0`、`avgRpm: null`。设备数据仍是 `source: "hardware"`；两类记录共存、可筛选，个人 CSV 标明来源。练习计时不显示设备曲线，不写入互动分享卡。退出登录并关闭标签页后，未保存草稿不保证保留；已保存记录存入后端。

### 记录查询

- `GET /api/breathing`：Bearer 用户认证，返回本人的 `sessions`，按开始时间倒序。亲友账号获取不到设备主人的记录。
- `GET /api/records?period=day|week|month&date=2026-10-29`：Bearer 用户认证。按北京时间自然日、周一开始的自然周、自然月计算。返回范围、统计、每日图表、四类灯语数、当期消息与本人当期呼吸记录。
- 送出数以消息创建时间计算；轻触数按指令的首次真实触摸时间计算，同一指令多次上报只计一次。合并灯语的单次触摸仍算一次。跨期触摸会落在触摸发生的周期。
- 统计查询所有已保存消息；解绑清除的配对消息不再统计。当前为黑客松轻量存储，达到容量限制返回错误，不静默丢弃；具体边界见 README。

## 导出

记录页日、周、月共用一个界面，可前后翻页或指定日期。互动 CSV 导出本期灯语和去重触摸时间，不含留言或原声。本人呼吸可单独导出全部采样 CSV，包含完整日期、设备、时间偏移和采样值。

“余光小花园”导出 1080×1440 PNG：花朵随本期送出与轻触数生成，最多画 24 朵，数字显示准确总数。先预览再下载或用手机系统分享。不包含姓名、留言、原声、呼吸值，不自动发布或自动邀请好友。分享图片之外的真实增长效果尚未验证。
