## 自动化测试（npm test）

9 项通过、0 失败（1 个完整流程测试内包含 8 个子测试）。使用临时独立 SQLite 与 3197 端口，验证后关闭并清理测试库，不影响 3100 的现场演示。

覆盖：

- 未登录与错误硬件密钥拒绝；发送方无法操作接收方专注，不暴露对方设备状态。
- 专注排队；解除后最旧优先，相邻同类合并；重复 pending 返回相同指令。
- 查询不等于送达；delivered 才改变状态；touch 才变为已收到；重复触摸幂等。
- 专注撤销尚未接收的指令，迟到确认及提前触摸被拒绝。
- 熄灯、离线不派发，上线后继续。
- 同一 clientId 不产生重复消息。
- 音频上传、用户授权读取；重启进程后会话、消息、音频仍存在。
- 任意一方解绑后消息清空、音频不可访问、指令取消、心跳要求停灯。
- 无效邀请码拒绝，新邀请码重新配对，一次性邀请码不可复用。
