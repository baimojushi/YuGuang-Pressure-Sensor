# 正式版与展示版

两版共用 public/ 和 shared/service.mjs；版本差异是服务端模式和存储空间，不是复制两套产品。后续功能改一次，两版同时生效。根目录与线上薄适配通过 sync-hosting 脚本同步和检查。

正式版：真实个人身份、空白初始资料、主动邀请码配对、本人绑定的设备和独立密钥。默认没有姓名、联系人、消息、原声、呼吸采样、练习或休息记录；没有模拟灯按钮与模拟接口。线上使用个人平台身份，本地使用独立账号密码。

2026-10-30 起，已配置的本机与线上正式版使用同一个 Supabase 正式空间和私有音频桶；账号身份仍区分本机密码与线上平台身份，两种登录不会自动合并为同一用户。展示版继续使用 SQLite / D1 与独立音频存储，不把示例数据写入 Supabase。

展示版：明确标记展示环境，只有这里提供小满与阿屿、自动配对和模拟灯。展示数据不导入正式空间，展示令牌和硬件默认密钥不能访问正式接口。旧本地数据和旧云端表保留，但不当作正式资料。

10 月 29 日对齐的交互：

- 情感连接为主线，呼吸与自主休息保留本人入口。
- 专注由本人手动切换；采样不用于自动判断情绪或大脑专注状态。
- 灯语一轮后自然淡出，无触摸不自动标为收到，也不会永久卡住队列。
- 设备传达状态不显示成亲友已读；主动触摸与主动按钮回应可以显示。
- 两端均可表达心意、附原声与快捷回复，每台灯只由本人绑定与控制。
- 不用回复／方便时回复是发送者选择的意图，不开启倒计时或升级提醒。
- 自由休息按持久化截止时间运行，离开页面仍继续；跟随呼吸练习切后台暂停。两种模式互斥。
- 休息到时用光与 App 提示，不主动震动；长触满 5 秒不额外生成短触回执。
- 本人传感器采样、本人练习计时、自由休息记录私有；互动 PNG 不包含私人留言、原声或呼吸值。
- 语音唤醒、真实触感引导、情绪日记和共同回忆不冒充首版已实现能力。

当前验证覆盖接口、持久化、个人隔离和模拟硬件协议。实际传感器算法、LED、电机、触摸固件、语音唤醒和扬声器仍需硬件同学完成与联调。

## 2026-10-30 统一账号与可选设备

注册只需称呼与账号信息。双方使用同一个 App，任何一方都能邀请、输入邀请码、发送、接收和主动回应。设备归属与亲友关系分开：没有玩偶也可以在手机上收发；每人最多绑定自己的一台玩偶；两人都有玩偶时分别接收发给本人的消息。专注、休息、设备心跳和采样不向亲友开放。

新配对保存 memberIds 两位成员；兼容读取旧 senderId / receiverId 配对字段。旧账号 role 字段不再用于限制权限，不批量改写旧记录、不重建账号、设备密钥或 Supabase 正式空间。连接成功及解绑都会使双方原有邀请码失效，避免旧码在解除连接后重新使用。

展示版保留两个示例账号与单台初始模拟灯，sender / receiver 查询参数只作为旧链接选择示例账号的别名，不代表产品角色。两版使用同一逻辑。双玩偶协议测试不等于两台硬件实测通过。

## 首页与单机双账号自测（2026-10-30）

首页保留关心的发送与最近一条收到的心意，留言 / 原声默认折叠。完整呼吸练习、记录、休息控制和大玩偶预览不再自动插入首页；功能仍可通过原导航及短入口进入。“呼吸与互动”内以“我的呼吸 / 互动记录 / 自由休息”切换，互动页保留同一界面的日、周、月切换与导出，消息明细按需展开。

本机正式版的用户令牌使用 sessionStorage，各标签页独立。亲友连接页的“打开另一个账号”链接带 rel=noopener，避免新标签页复制发起页的登录状态。第二页由本人注册 / 登录另一个真实账号；页面标题显示本人称呼以便区分。线上仍是平台个人身份，两个普通标签页不能自动变成两个不同平台用户。展示版可继续用两个独立的 as 链接进入示例账号。
