## 发现并修复

1. “已送出”原来按消息的未回应状态过滤，混入对方发来的消息、漏掉自己已经得到回应的消息。改为明确的“我送出的”，按 outgoing 方向过滤。浏览器复测：只显示自己送出，已主动回应的自己消息仍保留。
2. 互动 CSV 的主动回执被标为“已送出”。导出根据事件类型标为“主动回应”，下载后用 CSV 解析器核对所有回执行。
3. 损坏或不支持的音频播放失败时暴露英文底层错误。改为中文提示，释放当前播放状态；浏览器复测提示正确，随后仍可切换灯语。

## 经授权的录音测试与清理

用户明确允许临时录音并在测试后删除。内置浏览器的权限流程未完成，改用 Chrome 的临时页面。Chrome 显示录音开始，并生成 WebM；这次最终达到约 30 秒自动停止上限（长于原计划的几秒）。同机另一测试账号主动播放，实际 duration=29.88、currentTime=0.152294、paused=false、error=null。未转写、导出或上传该录音到外部服务。

授权面板最初显示 BlackHole 2ch 虚拟输入；授权期间页面状态由用户改变，未确认最终输入设备，因此不把此次结果宣称为内置物理麦克风或手机麦克风验证通过。

已停止回听、清除临时连接的所有音频并验证音频目录为空，关闭临时服务并删除整个临时测试目录。正式 Supabase 未参与录音测试。
