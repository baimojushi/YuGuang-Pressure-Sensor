# 队友交接面板

双击 `index.html` 即可使用，无依赖、不需要服务器。对外发交接 ZIP 时从根目录 `打开交接.html` 开始。

用途：体验入口、代码与协议入口、官方资料链接、非密板卡信息、10 项实物验收自报、进度 JSON 导入 / 导出、摘要复制。填写内容不上传、不自动保存；关闭前导出。勾选结果不代表系统自动检测通过。

2026-10-30 使用独立无登录浏览器验证：初始 0 项；计数更新；JSON 下载内容；重新打开不自动保留；导入恢复字段与检查项；无效文件拒绝且不覆盖；摘要复制 / 手动复制降级；390px 宽度无页面横向溢出；无自动网络请求和页面脚本错误。Postman 的 9 个请求模板均为合法 JSON，默认指向本地，设备 key 为空。

Postman 模板用于余光自己的设备业务协议。填有效 key 后请求会改变实际记录，电脑上报心跳也会使设备显示在线，不能据此宣称真机接入。灵机平台控制与回调 API 未取得，故不提供伪造的灵机 API 模板。真实呼吸采样请按协议单独上传，不用示例数据写入正式库。

同日追加：模板第 10 项为桌搭持续呼吸结果上报，数字变量按实际采样填入后才是有效 JSON；它不提供虚假默认频率。连续采集不再依赖抱住或手动开始，实时页面与自动归档协议见 `docs/持续呼吸采集.md`。关闭 App 后仍留存、无信号 / 断网 / 15 秒过期状态已在隔离本地浏览器实测，完整检查见 `docs/验收记录.md`。

打包：提交源码后，从项目根目录运行 `python3 scripts/package-handoff.py`。仅收录 Git 版本化文件，拒绝运行数据、`.env` 与特殊文件；ZIP 附源码 commit 和 SHA256 文件清单。
