# 实机接线与安全检查（XJWB03 ESP32-S3 / BF3901 / LD6002 / SG90）

## 摄像头转接板 H1 -> ESP32-S3

来自用户给出的转接板原理图和原 B 固件 `bsp_camera.h`，编号以**原理图电气针号**为准，不代表排针外观方向：

| H1 针 | 信号 | ESP32-S3 引脚 | 说明 |
|:---:|---|---|---|
| 10 | VCC | 3V3 | 转接板 ME6212 输出 2.8V；**VCC 不接 5V** |
| 9 | GND | GND | 与 MCU 共地 |
| 8 | SDA | GPIO21 | BF3901 SCCB/I2C |
| 7 | SCL | GPIO47 | BF3901 SCCB/I2C |
| 6 | VSYNC | GPIO4 | 1-bit SPI 采图的 CS；**不能用于舵机** |
| 5 | PWDN | GPIO41 | 摄像头掉电/使能 |
| 4 | HREF | 不接 | 1-bit SPI 模式不接 |
| 3 | D0 | GPIO8 | SPI 1-bit 数据输入；不要并用 MPU6050 SDA |
| 2 | D1 | 不接 | SPI 1-bit 模式不接 |
| 1 | PCLK | GPIO13 | SPI 数据时钟 |

注意：H1 物理正反面、1 号针的位置，仍以板子实际 1 号脚标识/万用表通断为准。原 B `bsp_camera.c` 已配置 XCLK 不外接，因为转接板自身 24MHz 晶振工作。GPIO4 被相机 CS 占用，不能复用。

## 雷达 LD6002

- `LD6002 TX0 -> ESP32-S3 GPIO18`，UART2 RX-only，1,382,400，8N1；原 B 源码已经实现 TF 协议和 v8 呼吸滤波。
- GND 与 S3 共地。**供电电压、TX 高电平必须用实物模块规格/示波器复核**；不要因串口是 3.3V IO 就推断模块电源也一定是 3.3V。
- 新版原始相位每样本附加 `esp_timer_get_time()`，进入 512 点环形缓存，随视频帧批量上传。UART 到达/解析时间不等于物理雷达测量真实时刻，两者有固定与随机延迟，属于**软件时间戳对齐**。

## SG90 水平舵机（带动摄像头 + 雷达）

| 舵机线 | 连接 |
|---|---|
| 红色 VCC | **独立 5V 电源**正极（建议至少 1A 级别，检查实际负载） |
| 棕色 GND | 独立 5V 电源负极，与 ESP32-S3 GND 单点共地 |
| 橙色 signal | ESP32-S3 **GPIO48**，LEDC 50Hz，3.3V PWM（需测试 SG90 是否稳定识别） |

- 请不要让舵机的大电流通过 ESP32-S3 GND 细线返回。可以在舵机供电端添加 470–1000μF 电解电容，注意极性。
- 切勿把舵机 5V 电源正极连接到 3V3。不要未经电源路径确认就把两路 5V 输出正极硬并联。
- 新固件默认 1,000–2,000 μs/50Hz（90°=约 1,500 μs），软件限 30–150°，每 40ms 最多变化 2°；这比原业务源码测试的极端 500–2,400 μs 更保守，不保证适配所有机械结构，必须实测。
- 强烈建议**首次测试拆下舵机摆臂**，先看 PWM 与角度再安装传感模组。舵机带不动整组模块可能发热、堵转或导致主控供电扰动。
- `YG_SERVO_DIRECTION=1/-1` 控制“人位于画面右侧时应该向哪个方向旋转”。测试错误时立即停止跟踪并改符号。
- 如果追踪人物可能超出左右限位，且要求始终可见，需要更大视场、两轴云台或重定位方案；单一 SG90 没法保证 360° 跟踪或视线遮挡后自动找到人。

## 局域网安全

该实现 HTTP token 在 **2.4GHz WPA2/WPA3 私有 LAN** 上使用；没有自带 TLS。局域网同网段第三方仍可能窃听，适合可信隔离网络测试。建议 PC 防火墙只放行固定 S3 IP，禁止路由器公网端口映射、禁止 Funnel。用于不可信局域网或正式商用时须补 HTTPS 双向证书或本地 VPN 与凭据轮换。必须征得被摄者和被测者同意，并限制报告保留时长。
