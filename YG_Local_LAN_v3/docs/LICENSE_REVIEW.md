# 商业部署与第三方组件授权核查

这个 ZIP 是对用户提供的源包的**重构版本**，不能因为源码能编译就自动推断所有部分具有独立转售许可。

- **继承源代码**：`sensor_esp32s3/main/bsp_camera.*`、`radar_ld6002.*`、`radar_tf_parser.hpp`、`radar_resp_filter_v8.h` 来自本次用户上传的原工程。其权利状态须沿用上游/原授权。新写的 Wi-Fi、HTTP、LED-C 控制和 PC 端代码也不自动重新授权第三方文件。
- **组件副本**：`sensor_esp32s3/components/` 来自原上传的 Espressif 组件，需分别保留并遵守其中的 LICENSE、NOTICE 文件；不能盲目视为单一统一许可证。
- **YOLO**：ONNX 模型权重**没有随包分发**。Ultralytics YOLO11 生态采用 AGPL / 商业授权等条款，闭源分发需核查模型训练权重、导出工具和部署方式的有效许可，不是改成 ONNX 就自动消除限制。
- **MoveNet**：Google MoveNet 的实现和具体权重应核查对应模型卡/许可证；这一替代路径可避开 YOLO 授权链，但也必须记录权重来源和文件哈希。
- **MediaPipe / ONNX Runtime / FastAPI 等**：遵守每个依赖自身许可证、NOTICE 和模型文件条款；在正式商用包内附第三方声明。
- **心理分类器**：没有附带训练数据或心理状态权重。上线需获得明确授权、有受试者同意、独立被试测试与模型适用性说明，不能把研发态代理评分当成客观压力或心理诊断。

**本交付不是法律意见或第三方权利保证**；建议在部署前形成一份包含代码、权重、数据、训练与运行库的 SBOM 和许可证记录。
